# CH002-002: Fault Data Admission

## Question

Which fault-system inputs can support a leakage-controlled CH-002 retrospective
experiment?

## Result

Completed as a source-admission decision. UCERF3 time-independent fault sections
and deformation alternatives are admitted only for issue dates on or after
2014-01-07. CH-002 therefore uses a 2014-2018 fit sub-window while preserving
the frozen 2019-2022 validation and unopened retrospective test.

UCERF3 time-dependent last-event data and current ComCat mechanism products are
deferred. NSHM23 data are prospective-only. Legacy Automata state values and
stress/strain proxies are excluded.

See [CH-002 Fault Data Inventory](../02-data/ch002-fault-data-inventory.md) for
the source-by-source rationale and acquisition gate.

## Skill Claim

None. No source was fitted, no forecast was generated, and no validation data
were read in this milestone.
